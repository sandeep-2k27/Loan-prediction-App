# Loan Prediction System

A machine learning based loan prediction system built using Python, Scikit-learn, and FastAPI.

## Features

- Predicts whether a loan application is likely to be approved or rejected
- Machine learning model trained using Scikit-learn
- FastAPI backend
- HTML and CSS frontend
- User-friendly loan prediction form
- Feature engineering and preprocessing before prediction

## Tech Stack

### Machine Learning
- Python
- NumPy
- Pandas
- Scikit-learn
- Random Forest

### Backend
- FastAPI
- Uvicorn

### Frontend
- HTML
- CSS
